## VO full (~180s spoken)

Incidents still die in five tools. IncidentRoom closes them in one Switch room.

A human reports checkout five-hundred. The triager routes. The reproducer proves it with a real command. The release agent drafts the stopgap — and waits.

This public demo mirrors that Switch room. Real agents run in Switch Console against Mattermost.

Watch one pass: classify, reproduce with output, propose a rollback with the risk named out loud.

Presets only seed the controls. Change severity, service, the log, or sensitivity — the room recomputes. It is not a frozen slide deck.

Disable an agent and it leaves the pass. Membership is the workflow.

Edit the command if you need to. Confirm puts your name on the production change. Dismiss withdraws it. The timeline stays for the next shift.

The YAML ships three agents: triager, repro, release. Without Switch, there is no room — and this project fails on purpose.

Agents prepare. Humans Confirm. IncidentRoom — for Flip the Switch, Best Business Workflow.
